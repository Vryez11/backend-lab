# lab09 — 파라미터 없이 열어도 죽지 않는 댓글 목록 (변형복습)

> 7/25 lab03(요청 파라미터 바인딩 TDD)의 변형복습. 같은 개념(요청 파라미터 바인딩·기본값·객체 바인딩)을 댓글 목록·등록 시나리오로 다시 손으로 증명한다.

## 배경 시나리오

동영상 게시판의 영상 상세 페이지에는 댓글 목록이 페이징으로 붙는다. 운영에서 다음 리포트가 올라왔다.

- "영상 페이지에 **처음 진입**하면(페이지네이션 파라미터를 아직 안 붙인 상태) 댓글 영역에서 **500**이 난다. 새로고침해서 `?page=0&size=10`이 붙으면 그때부터 정상이다."
- "댓글 **작성**은 프론트가 일반 폼(form) 전송으로 보내는데, 백엔드가 값을 못 읽어서 `author`/`content`가 빈 채로 저장된다."

`com.vryez.backendlab.lab09`에 댓글 조회·등록 API 두 개를 완성하라. 도메인·저장소·DTO·컨트롤러 골격은 깔려 있다 — **컨트롤러의 파라미터 바인딩과 응답만** 스프링 방식으로 완성하면 된다. 저장소는 인메모리이며 영상 1번에 댓글 12개가 미리 들어 있다.

## 요구사항

- `GET /videos/{videoId}/comments` — 댓글 목록. 쿼리 파라미터 `page`, `size`, `sort`, `keyword`.
- `POST /videos/{videoId}/comments` — 댓글 등록. 폼(form-urlencoded) 파라미터 `author`, `content`.

## 완료 조건

1. 파라미터를 **하나도 안 붙이고** `GET /videos/1/comments`를 호출해도 500 없이 200이 오고, 기본값 `page=0`, `size=10`, `sort=latest`가 적용된 목록이 온다.
2. `GET /videos/1/comments?page=1&size=5&sort=oldest` → 2번째 페이지, 5개, **오래된 순** 정렬로 온다.
3. `keyword`를 주면 `content`에 그 문자열을 포함한 댓글만, 안 주면 전체가 온다(나머지 파라미터 기본값은 유지).
4. `size=abc`처럼 **타입이 안 맞으면 500이 아니라 400**으로 응답한다.
5. `POST /videos/1/comments`에 폼 파라미터 `author`, `content`를 보내면 **201**과 함께 생성된 댓글(`id`, `author`, `content`, `createdAt`)이 JSON으로 오고, 이어서 목록을 조회하면 방금 등록한 댓글이 반영되어 있다.
6. 컨트롤러가 `HttpServletRequest.getParameter()` 등 서블릿 API를 직접 쓰지 않고, 응답도 문자열로 직접 JSON을 조립하지 않는다(스프링 바인딩·컨버터만 사용).

## 제약

- 서블릿 API 직접 사용 금지, 수동 JSON 조립 금지.
- 저장소·도메인·DTO 골격은 수정하지 않는 것을 기본으로 한다(필요하면 이유를 남길 것).

예상 소요 시간: **40~60분** (기초, 개념 1개).
